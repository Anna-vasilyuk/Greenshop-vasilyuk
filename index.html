Git Learning

Git Commands Reference

  • git init — Start a new local repository.
  • git clone [url] — Copy an existing remote repository.
  • git status — Check the state of your files.
  • git add [file] — Stage changes for the next commit.
  • git commit -m "[message]" — Save your staged changes.
  • git push — Upload local commits to GitHub.
  • git pull — Download and integrate remote changes.
